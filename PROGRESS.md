- Added an analysis budget gate for real videos, including Level 0-4 budget display, cost hints, audio-dependency prompts, and local canvas key-frame extraction.

- Added an isolated short-video playback concept demo screen, with ordinary playback UI separated from a hidden `Ctrl+U` local-material configuration mode.
- Refactored the app around shared `src/core/*` modules for budget gating, ad gating, card generation, card persistence, event logging, and trend aggregation.
- Split the page layer into `DemoFeedPage`, `CreatorCenter`, `InternalLab`, plus placeholder `MyCardsPage` and `ClipbookPage` routes so user, creator, and internal views share the same logic.
- Updated hidden demo-material configuration so it stores only raw inputs such as video metadata, tags, segment defaults, transcript, segment note, and ad candidate. Final card title, summary, and save reason are generated by `cardEngine`.
- Revised only the short-video playback page UI for recording mode: the workbench shell is hidden by default, top channels float over video, the right action rail uses transparent linear icons in short-video order, intro text no longer shows segment time, and the bottom tab returns to `首页 / 朋友 / + / 消息 / 我`.
- Added URL-driven page navigation for `demo`, `admin`, `internal`, `creator`, `profile`, `cards`, and `clipbook`, with the development navigation shown only when `dev=1`.
- Split hidden material configuration into `AdminConfigPage`, including return buttons for the clean demo page and the development navigation page.
- Added a short-video-style `ProfilePage` with platform-like profile actions, two creator-center entrances, a `卡片` tab, and simple routes to `MyCardsPage` and `ClipbookPage`.
